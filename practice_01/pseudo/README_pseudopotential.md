# Pseudopotential

Положите сюда Si pseudopotential, имя которого указано во входных файлах:

`Si.pbe-n-rrkjus_psl.1.0.0.UPF`

Если в вашей VM используется другой проверенный Si UPF, замените имя файла в блоке `ATOMIC_SPECIES` во всех inputs.
Важно: псевдопотенциал и выбранный XC functional должны быть согласованы.
